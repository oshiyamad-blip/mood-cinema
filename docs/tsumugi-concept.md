# Tsumugi — コンセプト設計

作成日 2026-07-09 / 旧称 **mood-cinema**（気分で選ぶ映画レコメンド）からのピボット。

## 何のアプリか（ひとこと）

**Tsumugi（シーン・スタジオ）は、脚本開発をスムーズにする統合エディタ。**
アイデア・人物・参考作品といった「素材」はそのまま置いておき、シーンの箱を並べた
タイムラインの上で、まとめてコントロールして一本の脚本に組み立てる。

## 比喩：動画編集ソフト

発想の軸は Premiere / Final Cut のような **NLE（ノンリニア編集）**。
素材は素材のまま溜め、タイムラインで束ねて制御する、という構造をそのまま脚本に写す。

| 動画編集ソフト | Tsumugi | 現状 |
|---|---|---|
| **メディアプール / ビン（素材）**<br>クリップ・音・写真を取り込んでそのまま置く | **素材**：アイデア/メモ・人物・**参考作品**・ログライン/テーマ・トーン | 参考作品＝旧レコメンドを転用。人物・メモは今後 |
| **タイムライン（編集）**<br>素材を並べて尺をつくる | **箱書き**：幕 → 箱（シーン）の並び。シーンのタイムライン | 実装済み（`/hako`） |
| **インスペクタ（各クリップの制御）** | 各箱に **人物・参考作品・トーン** を紐付けて制御 | 今後（箱は見出し＋本文のみ） |
| **書き出し（レンダー）** | アウトライン → テキスト →（将来）脚本フォーマット | .txt 書き出しのみ |

要点：**素材はそのまま、エディターとして束ねる**。これがそのまま情報設計になる。

## 旧 mood-cinema 資産の行き先

ピボットで捨てない。役割を変える。

- **レコメンド機能（気分バルーン → TMDB → 5本）** → 「**参考作品を探す**」素材ツールへ転生。
  「書いている物語のトーンに近い作品を、気分から引く」。TMDB 連携の投資がそのまま活きる。
  他の脚本ツールに無い、**メディアプールに映画そのものを置ける**固有の強み。
- **特集記事** → SEO 集客の入口として維持。今後「脚本の書き方」側の記事も足せる。
- **アフィリエイト / AdSense** → 参考作品カードに自然に残す（観る人の導線も殺さない）。

## 情報設計（ピボット後）

- **ホーム `/`** — 書く人向けのランディング。ヒーローCTAは「エディタを開く」。
  下に「創作ワークスペース（エディタ）」「参考作品を探す」「特集記事」。
- **エディタ `/hako`** — アプリの主役。箱書き（幕→箱）。今後ここに素材パネルを統合。
- **参考作品 `/mood` → `/result`** — 気分/トーンから参考作品を引く素材ツール。
- **特集 `/articles`**・**運営 `/about` 等** — 維持。

## ロードマップ（この先の素材→エディタ統合）

1. **人物マスタ**：登場人物を素材として登録し、箱（シーン）に紐付け。
2. **参考作品を箱に紐付け**：「この箱はこの作品のトーンで」を保存。素材プールと箱をつなぐ。
3. **インスペクタ**：箱を選ぶと右側で人物・参考作品・トーン・尺目安を制御。
4. **書き出し強化**：テキストに加え、脚本フォーマット（柱・ト書き・セリフ）やあらすじ生成。
5. **トーンボード**：参考作品のスチルを並べたムードボードを素材化。

## 命名・文言の原則

- 主語は常に **「書く人」**。「観る人」向けの言い回し（診断する・今夜のおすすめ 等）は
  「参考作品を探す・近いトーンの作品」など**制作の素材**を指す言葉へ。
- バイリンガル（`ja.ts` / `en.ts` 同形）を維持。ブランド表記は **Tsumugi**。
