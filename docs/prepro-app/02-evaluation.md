# 検討：5アプリを日本語の1アプリにまとめる価値・可能性・シナジー

作成日 2026-10-12。前提の事実関係は `01-research.md` を参照。

## 1. 結論

まとめる価値はある。理由は、5本が担う工程（構図確認・台本分析・配置図・スケジュール・
現場運用）が実務では一本の流れであるのに、海外では5本の別アプリに分断されてデータを
手で写し直しているからだ。日本には香盤表という、台本ブレイクダウン・スケジュール・
当日連絡を一枚でつなぐ中間文書が慣行として既にあり、これをデータモデルの背骨にすれば
海外ツールが持たない一貫性を最初から設計できる。日本語UIで同じ領域を覆う製品は
Creators Note（iOS限定、月¥1,540、知名度低）しかなく、競争上の空白も大きい。

実現は可能である。5本はいずれも数名以下で作られており、特に CineFlo は個人開発で
台本取込からコールシート配布までを iOS/Android/Web に載せている。難所はビューファインダーの
レンズデータベースで、ここだけは初期に簡易実装へ留める。

ただし市場は小さい。狙う顧客は日本の自主映画・短編・縦型ショートドラマ・小規模CM/MVの
制作現場であり、見込める有料ユーザーは数千人規模である。VC型の急成長ではなく、
CineFlo や Cadrage のように少人数で黒字を出す小さな事業として設計するのが正しい。

## 2. 統合に価値がある理由

### 2.1 工程は一本、ツールは五本
動画の投稿者自身が Scriptation でブレイクダウンし、StudioBinder でスケジュールを組み、
CineFlo でコールシートを配り、Shot Designer で配置図を描き、Cadrage で構図を撮っている。
台本のシーン番号・登場人物・場所は、この5本すべてに手で入力し直される。台本が改訂されれば
5か所を直す。統合の価値はこの再入力と不整合をゼロにすることに尽きる。

### 2.2 日本には「香盤表」というハブがある
ハリウッドでは Breakdown Sheet・Stripboard・Day out of Days・Call Sheet が別文書で、
StudioBinder はそれを別画面として再現している。日本の助監督はそれらを香盤表一枚に畳み、
総スケと日々スケに展開する。つまり日本の実務は最初から「一つの表から全部を出す」構造を
持っており、統合アプリと相性が良い。海外ツールの日本語化ではなく、香盤表を中心に
設計し直すことが差別化の核になる。

### 2.3 競争空白
日本語UIで香盤・スケジュール・コールシートを扱えるのは Creators Note だけで、
ビューファインダーはArtemis Pro が日本語対応しているのみ、ブロッキング図とコールシート配布は
国産に存在しない。StudioBinder 型の「無料テンプレート記事で検索流入を取る」集客も、
日本語の香盤表・日々スケ・絵コンテのテンプレート記事がほぼ無いため、そのまま空いている。

### 2.4 需要は増えている
邦画公開本数は年約700本、PFFアワード応募は795本で3年で急増し、縦型ショートドラマは
月数十本を量産する体制が74社規模で立ち上がっている。量産現場ほど香盤とスケジュールの
作り直しが頻発し、Excel手作業の限界が早く来る。

## 3. 実現可能性

### 3.1 技術
台本解析・香盤生成・スケジュール・コールシート・ショットリスト・絵コンテは、
通常のWeb/モバイル技術で実装できる。CineFlo がオフラインファーストでこれを1人で
作っている事実が上限の証明になる。ブロッキング図は2Dキャンバス（人物・カメラのアイコンと
動線）で十分で、Shot Designer の3D化は12年実現していない以上、不要と判断する。

ビューファインダーだけは性質が違う。正確な画角再現にはカメラのセンサーサイズと
レンズの実焦点距離のデータベースが要り、Cadrage は数千機種を10年以上かけて整備している。
初期版では「スマホカメラの既知の画角を基準に、指定したセンサー・焦点距離相当へクロップし、
任意アスペクトのフレームラインを重ねる」簡易版に留め、Cadrage や Artemis で撮った
写真を取り込んでショットに紐づける連携で補う。これで動画が示した「スマホで構図を試す」
体験の8割は満たせる。

### 3.2 プラットフォーム
助監督と制作部が香盤・スケジュールを組む作業は大画面（PC/タブレット）、現場での
日々スケ閲覧・ショット消し込み・ビューファインダー・ロケハン撮影はスマホである。
したがってWebアプリとスマホアプリの両方が要るが、CineFlo と同様に一つのコードベースから
Web・iOS・Android へ出す方針を取る。詳細は要件定義書の技術方針に記す。

### 3.3 法務・運用
固有の規制はない。特定商取引法表記、個人情報保護法に沿ったクルー連絡先の取り扱い、
ストア規約に沿ったプライバシーポリシーがあれば公開できる。コールシートには住所・電話番号
が載るため、配布リンクの有効期限と閲覧権限は必須要件とする。

### 3.4 事業規模の現実
料金は Excel無料・Creators Note月¥1,540・CineFlo月¥1,070 と比べられる。個人向けは
月¥980前後、作品単位のチームプランで制作会社から取る設計が妥当で、有料1,000人で
月商約100万円、作品プラン50本併用で月商約150〜200万円が現実的な初期目標になる。
大きくはないが、少人数で回る事業として成立する水準である。

### 3.5 採用の経路
日本の助監督・制作部はフリーランスで作品ごとに現場を移る。製品はチーム導入ではなく、
個人の助監督が一人で香盤を組める段階で価値が完結していなければ広がらない。
無料枠で個人が使い始め、その人が次の現場に持ち込み、配布機能が必要になった時点で
作品プランに移る。この経路を前提に、個人単独で完結する機能を優先する。

## 4. 統合で生まれるシナジー機能

単に5本を並べるのではなく、同じデータを共有することで初めて成立する機能を挙げる。
これらが統合アプリの存在理由であり、要件定義の中核になる。

### S1 台本から香盤表・総スケ・日々スケが一気通貫で生成される
縦書き台本を取り込むと柱からシーンが起こされ、登場人物と場所が自動でタグ付けされて
香盤表のマトリクスが生成される。香盤表のシーンを撮影日に割り当てると総スケになり、
撮影日を選ぶとその日の日々スケ（コールシート）が自動生成される。Scriptation の
ブレイクダウン、StudioBinder のスケジュール、CineFlo のコールシートが一つの表の
三つの見え方になる。

### S2 改訂稿に全部が追従する
台本が改訂されたら差分を取り、シーン番号・人物・場所の変化を香盤表・スケジュール・
ショットリスト・配置図へ波及させ、変わった箇所を強調表示する。Scriptation が注釈だけに
提供している Note Transfer を、プリプロの全成果物に広げる。日本の改訂稿運用（改訂日・色）
に合わせて版を保持する。

### S3 ショットの三位一体：ショットリスト・配置図・構図写真
1ショットが「リストの行」「俯瞰配置図上のカメラ位置と動線」「ビューファインダーで撮った
構図写真（焦点距離・アスペクト・方位・GPS付き）」の三つを同時に持つ。配置図でカメラを
動かすとショットリストの画角欄が更新され、現場でその写真を見ながら立てられる。
Shot Designer と Cadrage の分断をなくす。

### S4 時間の整合チェック
各ショットに見積秒数（段取り・本番）を持たせ、シーン・撮影日に積み上げて、日々スケが
その日の拘束時間に収まるかを警告する。ロケハン写真のGPSと太陽軌道から、屋外シーンの
撮影可能時間帯を算出してスケジュールに表示する。Cadrage の太陽追跡と CineFlo の
ゴールデンアワー表示を、スケジュール側で意味のある判断材料に変える。

### S5 現場モードと翌日への自動繰り越し
当日の日々スケ、ショットリストの消し込み、配置図、ビューファインダーをオフラインで
一画面に出す。撮了したショットを消し込むと進捗が共有され、撮り残しは翌日以降の
スケジュールへ繰り越し案として提示される。日報（撮影報告）は消し込み結果から
自動で下書きされる。

### S6 キャスト・スタッフのNG日と配布を一つに
人物マスタにNG日と連絡先を持ち、総スケを組む時点でNG日の衝突を警告する。
日々スケの配布はPDFとWebリンクで行い、日本の現場で主流のLINEにそのまま貼れる
短縮リンクと既読確認を備える。

### S7 絵コンテの自動下書き
ショットリストと構図写真から、日本式の縦長絵コンテ（カット番号・画・内容・セリフ・秒数）を
自動で組み、画は写真または空枠にして手描き差し替えできるようにする。

### S8 無料テンプレートによる集客（製品機能としてのテンプレート）
香盤表・総スケ・日々スケ・絵コンテ・ショットリストを、アプリを使わなくても使える
Excel/PDFテンプレートとして公開し、同じ書式でアプリに取り込める。StudioBinder の
集客モデルを日本語圏で再現しつつ、Excel運用からの移行コストを下げる。

## 5. 統合しないと決めるもの

スコープを守るために、海外5本が持っていても初期版では意図的に外すものを決めておく。
予算管理（CineFlo・StudioBinderにある）は日本の制作部がExcelと会計ソフトで扱っており
データ連携が薄いので外す。正確なレンズデータベースを持つビューファインダーは簡易版に
留める。脚本執筆エディタは持たず、取り込み専用とする。AIによる自動ブレイクダウンは
あとから足せる補助機能として第3フェーズに置き、既定では無効にする。
