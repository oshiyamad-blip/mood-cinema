# プリプロダクション統合アプリ企画（既存プロダクトとは独立）

Instagramリール https://www.instagram.com/reel/Dd4IuJnIjV4/ で紹介された海外のプリプロ5アプリ
（Cadrage / Scriptation / CineFlo / StudioBinder / Shot Designer）を起点にした新規企画の資料。

1. `01-research.md` — 動画の内容、各アプリの日本語対応・機能・マネタイズ、日本の既存状況、リリース可否
2. `02-evaluation.md` — 日本語で1本にまとめる価値と実現性、統合で生まれるシナジー機能
3. `03-requirements.md` — 要件定義書（仮称 KOBAN）
4. `04-basic-design.md` — 基本設計書（構成・データ・同期・アルゴリズム・画面・帳票）
5. `05-detailed-design.md` — 詳細設計書（フェーズ1：関数・SQL・画面項目・帳票寸法・入力規則・エラー・テスト）
6. `06-ui-design.md` — UIデザイン仕様書（色・文字・余白・部品の状態・画面ごとの要点）。モックアップは https://claude.ai/artifact/YUcX4b6stykqjVZNryNkhN
7. `07-improvement-proposals.md` — 改善提案12案（顧客の絞り込み、話数のデータモデル、Web先行・課金後ろ倒し、Excel取り込みの前倒しなど）
8. `08-adversarial-review.md` — 敵対的レビュー報告（競合の出現、同期と権限の致命的な穴、香盤表の画面密度など。修正は未着手）
9. `09-business-review.md` — ビジネス面の敵対的レビューと現場調査（端末はスマホが主役、フェーズ1から iPhone ネイティブを推奨、作る前の4週間の検証）
