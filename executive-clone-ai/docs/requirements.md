# 要件定義書：経営者クローン AI システム

## 1. プロジェクトの背景と目的

- 経営者の意思決定の仕組みや思考をデジタル化して再現する
- 経営企画や部門長が経営者と会議を行う前に AI と壁打ちを行う
- この事前準備により会議の回数を削減して意思決定の速度を劇的に高める
- 経営者自身が気づいていない潜在的な行動の因果関係を抽出して経営の資産とする

## 2. システム全体像

```
日常言動 → 集約 → シグナル抽出 → ストーリー構築 → 対話インターフェース
```

- 経営者の日常的な言動をすべて集約
- 経営に重要な情報のみをシグナルとして取り出す
- 過去の意思決定の文脈をストーリーとして整理
- これらを統合したデータベースを基盤に対話インターフェースを提供

## 3. 機能要件

### 3.1 マルチソースデータ収集

| ソース | 実装 | ステータス |
|--------|------|----------|
| Slack | `src/collectors/slack.ts` | ✅ 実装済 |
| Gmail | `src/collectors/gmail.ts` | ✅ 実装済 |
| Google Calendar | `src/collectors/calendar.ts` | ✅ 実装済 |
| Google Meet（会議録音） | 手動アップロード → voice.ts | ✅ 実装済 |
| 音声ライフログ | `src/collectors/voice.ts`（Whisper） | ✅ 実装済 |
| LINE | 未実装（LINE Business API 要調査） | ⬜ 未実装 |
| Google Docs | MCP 経由（`mcp/google-workspace/`） | ✅ 実装済 |

### 3.2 シグナル抽出

Claude API で以下のカテゴリに分類して Notion DB へ保存：

- `hypothesis`: 新しい仮説・気づき
- `key_person`: 外部の重要人物との接触
- `idea`: 新規・既存事業へのアイデア
- `policy`: 経営方針・重要意思決定
- `market`: 業界トレンド・競合他社情報
- `other`: 上記に当てはまらない重要情報

除外基準: 挨拶・雑談・日程調整・定型報告

### 3.3 ストーリー分析・構築

ステップ:
1. **初期設定**: 成功体験・失敗体験パターンを Notion に手動登録（15〜20 件目安）
2. **自動抽出**: シグナル DB を週次でバッチ分析（`npm run story`）
3. **関連性検出**: Claude API が因果関係を持つナラティブを自動生成

### 3.4 意思決定シミュレーション対話

- **経営理念プロンプト**: Notion の意思決定ルール DB（優先度順 15 件）を毎回注入
- **思考の再現**: シグナル・ストーリーを文脈として与えた上で一人称回答
- **根拠の明示**: 参照したシグナル ID・ストーリー ID を回答末尾に列挙
- **疑似ログ再入力**: 対話テキストは将来的にシグナル DB へ循環（TODO）

### 3.5 データ名寄せと統合

`src/lib/dedup.ts` — Jaccard 類似度（≥ 80%）+ 時刻ウィンドウ（±5 分）で重複検知・マージ

## 4. 非機能要件

### 4.1 セキュリティと権限管理

- `ALLOWED_EMAILS` 環境変数で対話インターフェースへのアクセスを制限
- `INTERNAL_API_SECRET` でバッチ ↔ API 間を認証
- Anthropic API はデータ学習除外エンドポイントを使用（[Anthropic Privacy Policy](https://www.anthropic.com/legal/privacy)）
- `robots: noindex` により外部検索エンジン非公開

### 4.2 システム反映頻度

| 処理 | タイミング | 実行方法 |
|------|----------|---------|
| データ同期・シグナル抽出 | 日次（例: 毎朝 6 時） | `npm run collect`（cron） |
| ストーリー生成 | 週次（例: 日曜深夜） | `npm run story`（cron） |

## 5. 開発プロセスと技術選定理由

| 選定 | 理由 |
|------|------|
| Claude API | 日本語品質・データ学習除外 API・Tool use |
| Next.js（App Router） | API Route でバックエンドを内包、Vercel デプロイ |
| Notion | 一覧性・人間による目視確認のしやすさ |
| MCP | Google Workspace 等の社内データへの安全なアクセス |
