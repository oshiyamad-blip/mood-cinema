## ホンヨミの位置づけ

### 勝っているところ（維持すべき強み）
1. **Android + iOS + Web の3面展開** — セリフAI・ColdRead・Rehearsal ProはiOSのみ。**日本のAndroidシェア（約3〜4割）とWebお試しは空白地帯**
2. **完全無料（全機能）** — 競合は買い切り$19.99/サブスク/機能制限つき無料
3. **写真OCR取り込み** — 紙台本が主流の日本の現場で唯一級。競合はPDF/テキストのみ
4. **縦書きPDFの行復元・表紙/人物表の自動除外** — 日本の台本形式への最適化
5. **プライバシーの明確さ** — 台本を端末外に出さない設計を明文化（ColdReadと同水準、セリフAIは不明）
6. **つまずき検出（リザルト）** — チラ見/言い直し/所要時間から詰まりを推定。**全競合に無い**
7. **つまずいたところだけ部分練習** — 検出→反復のループも独自（2026-07-08実装）

### 負けているところ（テーブルステークスの欠落）
1. **自分の声の録音** — Rehearsal Pro・LineLearner・Script Rehearser・セリフAIが対応。「TTSでなく人の声（自分/共演者）で練習したい」需要に未対応 → **最優先の追加開発**
2. **バックグラウンド再生** — 聞き流しを画面オフ/移動中に（セリフAI対応済み）
3. **台本・練習データの共有** — LineLearner/セリフAIにあり。稽古場のグループ利用で効く
4. **セルフテープ（自撮り録画）** — 英語圏では標準機能。日本でもオーディションの録画提出は増加中
5. 実績・レビュー数 — 後発ゆえゼロから

### 差別化の軸（マーケティングメッセージ）
- 「**紙の台本を写真で撮るだけ**」（OCR×縦書き×表紙除外 = 日本特化の取り込み体験）
- 「**どこでつまずいたか教えてくれる**」（検出→部分練習の稽古ループ）
- 「**全部無料・台本は端末から出ない**」（広告のみ・プライバシー）
- 「**AndroidでもiPhoneでもPCでも**」

## 追加開発の優先順位

| # | 機能 | 理由 | 規模 |
|---|---|---|---|
| P1 | **自分の声の録音・聞き返し**（練習中に自動録音→リザルトで再生） | 全競合が持つ基本機能。つまずき検出と組み合わせると「詰まった箇所の自分の演技を聞き返す」独自体験に | 中 |
| P2 | **バックグラウンド聞き流し** | 移動中の耳練習はセリフ暗記の主要シーン | 小〜中 |
| P3 | **台本共有（ファイル書き出し/読み込み）** | 稽古場のグループ導入の起点。バイラル効果 | 小 |
| P4 | セルフテープ（録画） | 需要は確実だが実装大。P1の音声録音で一部代替 | 大 |
| 済 | つまずき部分練習 | 差別化ループの完成（本analysisと同時に実装） | — |

## 脅威と時間軸
- セリフAIがAndroid版を出すと「日本語特化×Android空白」の優位が半減する。**先にAndroidでの認知を取るのが最重要**
- 英語圏AI系のセルフテープ+AIフィードバック潮流は12〜18ヶ月で日本に来る想定。P1の録音基盤はその布石になる
