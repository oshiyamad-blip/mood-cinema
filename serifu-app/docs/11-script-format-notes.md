# 日本式脚本の書式ノート（解析器の設計根拠）

パーサ（`lib/parser/rule_based_parser.dart`）が前提とする日本の脚本書式の整理。
新しい書式パターンを見つけたら、ここに追記 → テスト追加 → パーサ更新の順で反映する。

## 基本原則（ユーザー方針）

- **1行にセリフとト書きは同居しない** → 判定は行単位で行う
- ただし**行をまたぐセリフ・ト書きは存在する** → 連結ルールで1ユニットにまとめる

## シナリオ形式（映像：映画/ドラマ/ラジオ）の3要素

| 要素 | 書式 | パーサの扱い |
|---|---|---|
| **柱（はしら）** | 行頭に「○」＋場所・時間（例：`○駅前・朝`） | ト書き（`○◯●□■※☆…` や `第N場/幕/景` で判定） |
| **ト書き** | **行頭3字下げ**で書き、**折り返しも3字下げで頭を揃える**。人物の動き・状況説明 | 地の文/字下げ行＝ト書き。**連続する地の文は1つに連結**（折返し対応） |
| **セリフ** | `人物名「セリフ」`。**2行目以降は1字下げ**で「」が閉じるまで続く | `名前「…` で開始、`」`が現れるまで後続行を連結 |

## 戯曲形式（舞台）

- **役名だけの行**の下に、字下げしたセリフが続く形式が一般的：
  ```
  太郎
  　おはよう、花子。
  　今日はいい天気だね。
  ```
- パーサ：辞書にある役名のみの行→話者ブロック開始。空行/次の構造行まで連結して1セリフ

## その他の頻出パターン

| パターン | 例 | 扱い |
|---|---|---|
| コロン形式セリフ | `太郎：おはよう` | 名前が**役名辞書にある場合のみ**セリフ（`場所：公園` `時：昼` の誤爆防止） |
| カッコ完結行 | `（ため息をつく）` | ト書き |
| 登場人物ブロック | `登場人物`見出し＋名前列挙 | 役名辞書へ（出力しない） |
| ページ番号 | `12` / `- 3 -` | 無視 |
| セリフ内の小ト書き | `太郎「（笑って）ありがとう」` | セリフの一部としてそのまま読む（分割しない） |

## 役名辞書（2パス方式）

1. パス1で辞書構築：①登場人物ブロック ②`名前「`形式（高信頼・即採用）
   ③`名前：`形式は**同名2回以上**で採用（見出し除外）。
   ①②が皆無のコロンだけの台本では③を全て採用
2. パス2で辞書を使って行を分類

## 既知の限界（LLM解析で将来吸収）

- OCR由来の崩れ（字下げ消失・「」欠落）→ 修正UI頼み
- 役名の表記ゆれ（太郎/タロウ）の名寄せ
- 縦書きPDFの抽出順
- コロン形式で1回しか出ない役（辞書に載らず→ト書き扱い）
