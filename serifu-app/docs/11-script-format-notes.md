# 日本式脚本の書式ノート（解析器の設計根拠）

パーサ（`lib/parser/rule_based_parser.dart`）が前提とする日本の脚本書式の整理。
新しい書式パターンを見つけたら、ここに追記 → テスト追加 → パーサ更新の順で反映する。

## 基本原則（ユーザー方針）

- **1行にセリフとト書きは同居しない** → 判定は行単位で行う
- ただし**行をまたぐセリフ・ト書きは存在する** → 連結ルールで1ユニットにまとめる

## シナリオ形式（映像：映画/ドラマ/ラジオ）の3要素

| 要素 | 書式 | パーサの扱い |
|---|---|---|
| **柱（はしら）** | 行頭に「○」＋場所・時間（例：`○駅前・朝`） | ト書き（`○◯●□■※☆…` や `第N場/幕/景` で判定） |
| **ト書き** | **行頭3字下げ**で書き、**折り返しも3字下げで頭を揃える**。人物の動き・状況説明 | 地の文/字下げ行＝ト書き。**連続する地の文は1つに連結**（折返し対応） |
| **セリフ** | `人物名「セリフ」`。**2行目以降は1字下げ**で「」が閉じるまで続く | `名前「…` で開始、`」`が現れるまで後続行を連結 |

## 戯曲形式（舞台）

- **役名だけの行**の下に、字下げしたセリフが続く形式が一般的：
  ```
  太郎
  　おはよう、花子。
  　今日はいい天気だね。
  ```
- パーサ：辞書にある役名のみの行→話者ブロック開始。空行/次の構造行まで連結して1セリフ

## その他の頻出パターン

| パターン | 例 | 扱い |
|---|---|---|
| コロン形式セリフ | `太郎：おはよう` | 名前が**役名辞書にある場合のみ**セリフ（`場所：公園` `時：昼` の誤爆防止） |
| カッコ完結行 | `（ため息をつく）` | ト書き |
| 登場人物ブロック | `登場人物`見出し＋名前列挙 | 役名辞書へ（出力しない） |
| ページ番号 | `12` / `- 3 -` | 無視 |
| セリフ内の小ト書き | `太郎「（笑って）ありがとう」` | セリフの一部としてそのまま読む（分割しない） |

## 役名辞書（2パス方式）

1. パス1で辞書構築：①登場人物ブロック ②`名前「`形式（高信頼・即採用）
   ③`名前：`形式は**同名2回以上**で採用（見出し除外）。
   ①②が皆無のコロンだけの台本では③を全て採用
2. パス2で辞書を使って行を分類

## フロントマター（表紙・登場人物表）の除外

実際の応募台本には本編の前に**表紙（応募用紙・タイトル・作者クレジット）、
あらすじ、登場人物表**が付くことが多い。これらは読み上げ・稽古の対象外
（`LineType.meta`）として扱う：

- **表紙**：文書先頭から最初の構造行（柱／登場人物見出し／`名前「`）までを、
  区間内に表紙らしい項目語（タイトル・氏名・住所・あらすじ・作：… 等）が
  **2つ以上**あるときだけメタ化。表紙のない台本の冒頭ト書きは誤判定しない。
- **登場人物表**：`登場人物（表）/配役/キャスト` 見出し（点線などの飾り付きも可）
  から空行までをメタ化。説明付きの行（`田中一郎（28）　主人公。`）からは
  先頭の名前だけを役名辞書に登録する。
- **柱の記号**：`○`（記号）だけでなく `〇`（漢数字ゼロ）で書く台本も多い。
- 記号・罫線だけの飾り行（`………` 等）もメタ化。
- 役の一覧には**実際にセリフを話した名前だけ**を出す（人物表のフルネームと
  本文の短縮名の重複対策）。

## 縦書きPDFの行復元（pdf_layout_text.dart）

縦書き台本のPDFは素朴なテキスト抽出だと1文字ずつバラバラになる。
そこで文字の座標から視覚上の行を復元する：

1. ページごとにランのアスペクト比の多数決で縦書き/横書きを判定
2. 縦書きは x 座標で「列」をクラスタリング → 右の列から左へ、列内は上から下
3. 横書きは y 座標で「行」をクラスタリング → 上から下、行内は左から右
4. 列間/行間が中央値の1.8倍を超えたら空行（段落境界）を挿入
5. ページ端（先頭/末尾2行）で3ページ以上繰り返される定型行
   （応募用紙ヘッダー等。数字違いは同一視）を自動除去

## 既知の限界（LLM解析で将来吸収）

- OCR由来の崩れ（字下げ消失・「」欠落）→ 修正UI頼み
- 役名の表記ゆれ（太郎/タロウ）の名寄せ
- ルビ・2段組など複雑なレイアウトのPDF
- コロン形式で1回しか出ない役（辞書に載らず→ト書き扱い）
