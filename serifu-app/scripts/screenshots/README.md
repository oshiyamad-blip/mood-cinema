# ストア用スクリーンショットの自動生成

Web版（`build/web`）を Playwright で開き、主要画面をスマホ寸法（1290×2796＝
App Store 6.7"/6.9"）で撮影する。実機・エミュレータ無しで、現行UIの高解像度
キャプチャを再現可能に得るための道具。

## 使い方

```bash
# serifu-app/ で
flutter build web --release          # build/web を生成
cd scripts/screenshots
npm install                          # 初回のみ（Playwright を取得）
node capture.mjs                     # → out/*.png
```

CIやオフライン環境では canvaskit を CDN から取得できないため、スクリプトが
ビルド同梱の canvaskit を返すよう差し替える。日本語フォントはアプリが
NotoSansJP を同梱しているので追加設定は不要。

## 出力

`out/` に以下が出る（`samples/` に参考出力をコミット済み）：

| ファイル | 画面 | 使いどころ |
|---|---|---|
| `01-home.png` | ホーム（練習する／取り込む） | 「台本を選ぶだけ」の訴求 |
| `02-settings.png` | 設定（声・テンポ・返しの間） | 「芝居の“間”まで調整」 |
| `03-setup.png` | 台本の準備（役選択・声設定・台本内容） | 「役を選ぶと相手役をアプリが読む」 |

## 仕上げ（ストア提出用）

撮った素材はそのままでも使えるが、`docs/10-store-listing.md` の構成に沿って
キャッチコピーのオーバーレイ・端末フレームを load すると訴求が上がる
（Figma/Canva等）。App Store は 6.7"/6.9"、Play は同画像の縮小で可。

## 練習中（現在行ハイライト）の画面について

canvaskit はテキストをDOMに出さない（キャンバス描画）ため、役選択チップの
自動タップは不安定で、練習中画面まではこのスクリプトでは安定して到達できない。
その1枚が要る場合は Android エミュレータ / iOS シミュレータで `flutter run` し、
役を選んで練習画面を表示してからスクショを撮るのが確実
（実機フォントで最も忠実に描画される）。
